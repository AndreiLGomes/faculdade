Sobre o Projeto

Este site foi desenvolvido com o objetivo de apresentar um sistema simples e funcional de cadastro de usuários e um formulário de contato.

Os usuários podem adicionar seus nomes e e-mails, visualizar a lista e remover entradas. Também é possível enviar uma mensagem via formulário de contato, simulando o envio para um sistema de atendimento ou backend.

Toda a interface foi construída com foco em organização, acessibilidade e boas práticas de desenvolvimento. A lógica foi separada em arquivos específicos de JavaScript e CSS, garantindo melhor manutenção e legibilidade.

Além disso, o projeto preserva um script legado protegido, integrando-o com a estrutura moderna sem modificar suas funcionalidades originais.
